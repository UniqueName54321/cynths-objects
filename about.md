# Cynth's Objects

A collection of custom objects for the Geometry Dash editor, powered by
[Object Collab](https://geode-sdk.org/mods/smjs.object-collab).

## Currently included

- **Advanced Options Trigger** — a custom *trigger* that changes a level or
  player setting on the fly. It covers 172 options across 6 categories
  (Level Settings, Gameplay, Camera, Physics, Visual/Debug, Player), all
  browsable through a **searchable Option Browser** in the Edit Special screen.
  Type to filter by name, category, or key number, click an option to select
  it, and set the value with a slider. Markers show `[*]` for instant effects
  and `[!]` for settings that need a respawn/restart.

  Each trigger instance changes **one** setting to **one** value — place
  multiple triggers to change several settings at once.

More objects coming soon.
